# CPE 局域网 App 维护技能

## 使用时机

用于维护或扩展本仓库 **FiberHome LG6121F（已验证固件 RP0108）** 的 iOS 局域网控制 App。不要把这套流程套用到远程云端功能。

## 安全原则

1. 先只读检查 `README.md`、`文档/开发记录.md` 与 `app/`；不要访问用户路由器，除非用户明确要求并授权。
2. 始终在本地副本上改动。禁止把设备配置、密码、Keychain 数据、日志、短信和真实截图写入仓库。
3. 默认从只读状态开始。真实写入、无线关闭、网络制式切换、重启、定时任务保存及短信删除都是影响设备的操作，必须在测试设备上逐项验证。
4. 任何写操作需依据当前响应回读设备状态；单凭 HTTP 成功或“请求已接受”不可宣称设置完成。
5. 公开构建不得读取仓库外的私人 bootstrap 配置，不得将地址、用户名或密码嵌入二进制或安装包。
6. 不假设其他厂商、机型或固件兼容。主验证目标固定为 LG6121F / RP0108。
7. 收/发短信仅手动获取；不要添加后台自动轮询。短信正文和电话号码不能进入诊断日志。
8. 远程登录/远程短信属于另一个独立项目与仓库，不能把完整远控源码合入本仓库。

## 工作流程

1. 记录用户目标、目标机型和固件；无法确认时明确标注未知。
2. 仅先做代码审查、静态检查和合成数据测试。
3. 变更代码前备份本次工作副本并检查 Git diff；不改写原有共享工程。
4. 对 Web 静态资源执行 `node --check`；Python 文件执行 `python3 -m py_compile`；构建脚本执行 `sh -n`。
5. iOS 编译需要匹配的真实 iOS SDK 与使用者自己的签名工具。不可把当前 iSH 交叉编译的构建记录冒充 Apple 官方 Xcode 构建。
6. 在授权的测试设备上先测试只读，再测试会影响设备的动作；记录设备与固件，保留失败情况和恢复方法。
7. 发布前查 Git 状态、diff、仓库文件清单，扫描个人信息/私有地址/令牌/截图/安装包/Keychain/诊断输出。
8. 使用中文说明哪些结果是实机验证、模拟测试、静态分析或尚未验证，并说明 OpenAI 辅助开发但不暗示任何厂商背书。

## 目前已知事实

- 已实机验证：LG6121F / RP0108 局域网自动登录、状态读取、手动短信收发与逐条删除、离线错误提示、设置隔离与窄屏布局。
- 未逐一验证：所有控制开关写入、重启、定时重启落库、所有管理页分支及其他固件版本。
- 中兴 MU5120 是单独的 MiFi 本地适配对象，不是 LG6121F 型号，也不代表远程功能支持。
- 具体验证边界参见 `文档/开发记录.md`。
