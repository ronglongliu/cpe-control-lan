# 局域网 CPE 控制项目开发记录（脱敏）

## 项目身份

- App 名称：**CPE 控制**
- 设备厂商：烽火通信 / FiberHome
- 已实测 CPE：**LG6121F**
- 已实测固件：**RP0108**
- 平台：iPhone / iOS；Objective‑C 原生桥接 + 本地 Web 界面
- 开发说明：项目在 **OpenAI 辅助下开发**。下列实机结论由项目测试记录整理，不代表 OpenAI 或厂商承诺。

## 当前能力

- CPE 局域网内自动登录并读取运行状态、蜂窝网络信息、信号参数、流量与在线终端。
- 快捷控制项按设备返回字段呈现；变更后执行状态回读，避免仅凭提交响应报告成功。
- 提供固件管理页面入口、定时重启设置界面与手动重启操作入口。
- 手动刷新短信收/发箱，支持单条删除；未配置短信后台轮询。
- 支持 CPE 与 MiFi 分开保存地址和密码，使用 iOS Keychain 保存。
- 离线时显示明确失败状态；窄屏无明显横向溢出。

## 验证边界

在一台 LG6121F / RP0108 实机及当前 iPhone 环境中验证了登录、读取、短信收发/删除、配置隔离和界面行为。快照不含任何真实设备标识或账户内容。

以下项目尚未验证或没有完整覆盖：

1. 每个快捷开关均未在现网逐一执行写操作，避免意外改变设备配置。
2. 立即重启及定时重启是否在所有版本上稳定落库，尚未进行实机验证。
3. CPE 完整管理页自动登录路径未覆盖所有固件分支。
4. 其他 LG6121F 硬件批次、运营商定制固件、固件升级后的兼容性未知。
5. 局域网明文 HTTP 的风险、账号密码保护及后续支持政策需要持续评估。
6. 中兴 MU5120 仅作为独立局域网适配示例；并不等于其全部功能已覆盖或获得远程支持。

## 开发路线建议

- 建立多台设备/多固件版本兼容矩阵，优先做只读验证。
- 对所有会断网、重启或可能影响资费的操作补充二次确认和恢复提示。
- 逐项验证快捷写入、定时重启并记录可重复的脱敏测试步骤。
- 完善自动化离线测试、最低权限网络配置和版本升级说明。
- 对外分发前由使用者自行完成代码签名、依赖审核和安全评估。

## 协议及数据来源

功能来自自有设备上的局域网操作、固件响应观察及人工验证记录。仓库中不附真实路由器导出、抓包、短信、账户、令牌或设备 ID。所有代码只适用于获得授权的自有设备，不构成官方技术支持。
