# 烽火 LG6121F 局域网控制台

**把蜂窝网络状态、常用开关、流量和短信管理，集中到 iPhone 上。**

这是一个面向 iPhone 的中文 iOS 项目，主支持型号是烽火 **FiberHome LG6121F CPE**；已有实机验证固件为 **RP0108**。App 通过设备本地管理接口读取状态，并提供经过限制的设置入口。源码另包含独立的中兴 **ZTE MU5120 MiFi 局域网适配**；MU5120 是另一款 MiFi 设备，不属于 LG6121F CPE，也不应据此理解为该型号已获完整实机兼容验证。

> 本项目为独立社区开发项目，与烽火、FiberHome、中兴或 Apple 均无隶属关系。仅管理你本人拥有或获授权管理的设备。关闭 Wi‑Fi、切换蜂窝网络等操作可能导致当前管理连接中断。

## 已实现功能

- LG6121F：CPE 状态、蜂窝网络与信号、流量、在线设备信息。
- 移动数据、飞行模式、4G/5G 模式、SA/NSA、漫游、载波聚合、外置天线、短信功能、双频 Wi‑Fi 等快捷项；可用项以设备固件响应为准。
- 定时重启参数、立即重启及更多固件管理页面入口。
- 短信列表手动刷新、收发箱查看与逐条删除；短信刷新不启用后台轮询。
- CPE 与 MiFi 独立保存连接设置；密码留空保留已有设置，凭据保存在本机钥匙串。
- 设备数据卡片可折叠并记忆状态；窄屏布局已适配。
- 浏览器预览采用合成示例数据，所有写入、重启及短信发送在预览状态都会拒绝执行。

## 构建概况

这是 TrollStore/开发者工具链下的 iOS Objective‑C 项目，最低部署目标为 iOS 16。需要 iOS SDK、Clang/LLD、Python 3 与 Pillow、以及本机可用的代码签名工具。环境变量：

- `IOS_SDK`：可选的 iOS SDK 目录；默认指向用户目录下的 iOS 16.5 SDK。
- `IOS_SIGNER`：可选签名程序；默认使用 `ldid`。
- `OUTPUT_TIPA`：可选输出文件路径。

```sh
cd app
IOS_SDK="$HOME/.ios-sdk/iPhoneOS16.5.sdk" IOS_SIGNER=ldid ./build.sh
```

构建产物仅供自有设备测试。脚本不会从仓库外读取 CPE/MiFi 密码或把个人连接配置嵌入成品。签名能力、安装权限与证书由使用者自行准备；安装脚本和私人设备部署参数不包含在此仓库。

## 隐私与网络安全

- 首次连接前，在 App 内填写自己的设备管理地址与凭据。不要提交密码、序列号、IMEI/IMSI、电话号码、SSID、短信内容、日志、截图、钥匙串数据或完整设备响应。
- 一些旧式设备只提供 HTTP 局域网管理接口；该流量不具备 HTTPS 的传输保密性。请仅在可信的自有局域网内使用，避免在公共 Wi‑Fi 中登录。
- 公开源代码不包含任何预置登录信息；`app.js` 的浏览器预览只用人工合成样例。
- 请勿把真实短信、令牌或配置文件提交到 Issue、PR 或讨论区。
